========================================================
  TOUR GraphQL API - Postman & cURL Guide
  Base URL: http://localhost:8186/travel/graphql
========================================================

CÁCH DÙNG TRONG POSTMAN:
1. Chọn phương thức: POST
2. URL: http://localhost:8186/travel/graphql
3. Tab Body -> Chọn "GraphQL"
4. Copy phần nội dung trong mục "POSTMAN GRAPHQL BODY" phía dưới dán vào.

========================================================
  QUERIES
========================================================

--- 1. Get All Tours ---
[POSTMAN GRAPHQL BODY]:
{
  getAllTours {
    code
    message
    data {
      id
      title
      description
      price
      thumbnail
      duration
      startLocation
      createdAt
      updatedAt
      isDeleted
      category {
        id
        name
        slug
      }
    }
  }
}

[cURL]:
curl -X POST http://localhost:8186/travel/graphql \
  -H "Content-Type: application/json" \
  -d '{"query": "{ getAllTours { code message data { id title description price thumbnail duration startLocation createdAt updatedAt isDeleted category { id name slug } } } }"}'

-----------------------------------------------------------

--- 2. Get Tour By ID ---
[POSTMAN GRAPHQL BODY]:
{
  getTourById(id: 1) {
    code
    message
    data {
      id
      title
      description
      price
      thumbnail
      duration
      startLocation
      createdAt
      updatedAt
      isDeleted
      category {
        id
        name
        slug
      }
      schedules {
        id
        dayNumber
        title
        content
      }
      images {
        id
        imageUrl
        isPrimary
      }
    }
  }
}

[cURL]:
curl -X POST http://localhost:8186/travel/graphql \
  -H "Content-Type: application/json" \
  -d '{"query": "{ getTourById(id: 1) { code message data { id title description price thumbnail duration startLocation createdAt updatedAt isDeleted category { id name slug } schedules { id dayNumber title content } images { id imageUrl isPrimary } } } }"}'

========================================================
  MUTATIONS
========================================================

--- 4. Create Tour ---
[POSTMAN GRAPHQL BODY]:
mutation {
  createTour(input: {
    categoryId: 1,
    title: "Tour Đà Nẵng 3N2D",
    description: "Khám phá thành phố biển",
    price: 1500000,
    thumbnail: "https://example.com/danang.jpg",
    duration: "3 ngày 2 đêm",
    startLocation: "Hà Nội"
  }) {
    code
    message
    data {
      id
      title
      price
      category {
        id
        name
      }
    }
  }
}

[cURL]:
curl -X POST http://localhost:8186/travel/graphql \
  -H "Content-Type: application/json" \
  -d '{"query": "mutation { createTour(input: { categoryId: 1, title: \"Tour Đà Nẵng 3N2D\", description: \"Khám phá thành phố biển\", price: 1500000, thumbnail: \"https://example.com/danang.jpg\", duration: \"3 ngày 2 đêm\", startLocation: \"Hà Nội\" }) { code message data { id title price category { id name } } } }"}'

========================================================
  GHI CHÚ
========================================================
- Trong Postman tab GraphQL: KHÔNG dùng dấu gạch chéo ngược (backslash) trước dấu ngoặc kép.
- Chỉ copy nội dung trong [POSTMAN GRAPHQL BODY] dán vào khung soạn thảo Query của Postman.
- Nếu muốn dùng Variable, hãy tách phần input ra khung "GraphQL Variables" bên dưới trong Postman.
- Nếu có lỗi "Field must have selections", kiểm tra xem đã liệt kê các trường muốn trả về trong dấu { } sau tên hàm chưa.
