========================================================
  TOUR IMAGE GRAPHQL API - Postman & cURL Guide
  Base URL: http://localhost:8186/travel/graphql
========================================================

CÁCH DÙNG TRONG POSTMAN:
1. Phương thức: POST (GraphQL luôn dùng POST)
2. URL: http://localhost:8186/travel/graphql
3. Tab Body -> GraphQL:
   - Query: Nhập query/mutation
   - Variables: Nhập biến (nếu dùng biến)
4. Header: Content-Type: application/json

========================================================
  QUERIES
========================================================

--- 1. Get Images By Tour ID ---
[QUERY]:
query {
  getImagesByTourId(tourId: 1) {
    code
    message
    data {
      id
      imageUrl
      isPrimary
      createdAt
      updatedAt
    }
  }
}

[cURL]:
curl -X POST http://localhost:8186/travel/graphql \
  -H "Content-Type: application/json" \
  -d '{"query": "query { getImagesByTourId(tourId: 1) { code message data { id imageUrl isPrimary createdAt updatedAt } } }"}'

========================================================
  MUTATIONS
========================================================

--- 2. Add Image To Tour ---
[MUTATION]:
mutation {
  addImageToTour(input: {
    tourId: 1,
    imageUrl: "https://example.com/images/tour1.jpg",
    isPrimary: true
  }) {
    code
    message
    data {
      id
      imageUrl
      isPrimary
    }
  }
}

[cURL]:
curl -X POST http://localhost:8186/travel/graphql \
  -H "Content-Type: application/json" \
  -d "{\"query\": \"mutation { addImageToTour(input: { tourId: 1, imageUrl: \\\"https://example.com/images/tour1.jpg\\\", isPrimary: true }) { code message data { id imageUrl isPrimary } } }\"}"
