========================================================
  CATEGORY GraphQL API - Postman & cURL Guide
  Base URL: http://localhost:8186/travel/graphql
========================================================

CÁCH DÙNG TRONG POSTMAN:
1. Chọn phương thức: POST
2. URL: http://localhost:8186/travel/graphql
3. Tab Body -> Chọn "GraphQL"
4. Copy phần nội dung trong mục "POSTMAN GRAPHQL BODY" phía dưới dán vào.

========================================================
  QUERIES
========================================================

--- 1. Get All Categories ---
[POSTMAN GRAPHQL BODY]:
{
  getAllCategories {
    code
    message
    data {
      id
      name
      slug
      isDeleted
    }
  }
}

[cURL]:
curl -X POST http://localhost:8186/travel/graphql \
  -H "Content-Type: application/json" \
  -d '{"query": "{ getAllCategories { code message data { id name slug isDeleted } } }"}'

  MUTATIONS
========================================================

--- 5. Create Category ---
[POSTMAN GRAPHQL BODY]:

  createCategory(input: {
    name: "Phú Quốc",
    slug: "phu-quoc"
  }) {
    code
    message
    data {
      id
      name
      slug
    }
  }
}

[cURL]:
curl -X POST http://localhost:8186/travel/graphql \
  -H "Content-Type: application/json" \

========================================================
  GHI CHÚ
========================================================
- Trong Postman tab GraphQL: KHÔNG dùng dấu gạch chéo ngược (backslash) trước dấu ngoặc kép.
- Chỉ copy nội dung trong [POSTMAN GRAPHQL BODY] dán vào khung soạn thảo Query của Postman.
- Nếu muốn dùng Variable, hãy tách phần input ra khung "GraphQL Variables" bên dưới trong Postman.
- Nếu có lỗi "Field must have selections", kiểm tra xem đã liệt kê các trường muốn trả về trong dấu { } sau tên hàm chưa.
